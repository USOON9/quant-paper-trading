# 下一步完成：v3 时间目标与冻结实验

日期：2026-09-07。当前仅做离线研究，不下单，不自动选择/部署获胜模型。本次在已有缓存上完成独立美股/BTC 实验，原 v2 模型、观察数据库、报告和定时任务的运行前后 SHA-256 均一致；两层订单开关保持关闭。

## 这一步解决了什么

原来只说“预测下一天”，没有把行情何时完整、模型何时决策、标签何时可用于训练变成独立约束。现在每条样本显式记录六个 UTC 时间字段：特征日期、特征可用时间、决策时间、入场时间、退出时间、标签可用时间。

| 研究组 | 目标日 D 使用什么数据 | 决策时间 | 价格标签 |
| --- | --- | --- | --- |
| 美股/ETF | 精确上一 XNYS 交易日的完整日线 | D 日 00:30 UTC | D 日正式开盘至正式收盘的价格代理 |
| BTC | D−2 日完整日线，特意多滞后一天 | D−1 日 00:30 UTC | D 日 00:00 至 D+1 日 00:00 的日线价格代理 |

美股使用交易日历处理假日、提前收盘和夏令时。BTC 不再在前一根日线尚未完成时，假设已经看到了其收盘数据。滚动特征需要完整的连续 21 个预期交易时段；缺失必要日期就排除该样本，不能自动找更老的一天替代。

这是一套**时间上可行的日线研究约定**，并不是已经验证可成交的模型。Yahoo 调整后 OHLC 仍不是历史 PIT 原始报价；开盘/收盘价格也不是本账户保证能成交的价格。30 分钟数据发布缓冲是我们的假设，不是供应商服务保证。后续必须用报价、成交量、下单截止时间和延迟验证入场方式。

## 实验规则先冻结，再看结果

规则存于 `configs/research_v3.toml`：

- 研究数据截止 2026-09-03；2026-09-08 起只作为保留的未来研究边界，本轮没有生成 v3 forward 预测，也未开始 v3 交易。
- 美股组 SPY/JPM/XOM/WMT/JNJ 与 BTC 组独立训练和评估，不共享一个拟合模型，也不把收益混成一个数。
- 三个预声明基线：训练集上涨比例、逻辑回归、当前梯度提升树。没有调参搜索，没有事后调阈值，只做这一轮比较。
- 固定 long/flat：概率达到 0.55 才假设做多，其余持现金；没有加密货币裸空、股票借券或期权交易。
- 每组 6 折 expanding walk-forward，每折最多 252 个该组日期；至少 1,260 个训练日期，留 5 个 purge 日期。
- 另外强制 `最后训练标签可用时间 < 第一条测试决策时间`，相等也不允许。不是仅仅把特征行号错开。
- 美股完整往返成本压力场景为 0/5/10/20 bps，主场景 5 bps；BTC 为 0/10/25/50 bps，主场景 25 bps。这些是预设工程压力假设，不是经核对的实际费率。
- 不论分数多少，`research_only=true`、`executable_backtest=false`、`promotion_disabled=true`；不生成可部署 joblib，不改变 Paper 准入。

运行开始前写入 manifest，记录协议、所有输入数据、源码和依赖版本的哈希；解析输入及计算结束后再次核对。结果只能写入新的 `artifacts/research-v3/<run-name>/`，已有目录、路径越界或 symlink 跳转会被拒绝。只有全部结果成功写完，才发布 `completion.json`。中断目录保留证据，不能伪装成完成。

哈希用于核对，不是数字签名，也不是源码/原始数据归档。若要多年后完整重现训练，还需要版本控制和只读数据快照。历史数据在先前研究中已经被查看，冻结本轮规则不能把旧历史重新变成全新 holdout。

## 实际结果：不是换大模型就会好

本轮研究目录：`artifacts/research-v3/20260907-timing-baseline/`。美股数据集 32,930 行、样本外 7,560 行；BTC 数据集 4,348 行、样本外 1,512 行。全部三个候选共保存 27,216 条按折时间外预测。

两组因交易日不同而有不同评估窗口，不能直接排名其收益：美股为 2020-08-27 至 2026-09-03；BTC 为 2022-07-15 至 2026-09-03。

| 组别 / 模型 | AUC | 扣主场景成本累计收益 | Sharpe | 最大回撤 |
| --- | ---: | ---: | ---: | ---: |
| 美股 / 比例基线 | 0.5012 | 0.00% | 0.000 | 0.00% |
| 美股 / 逻辑回归 | 0.4984 | +3.66% | 0.164 | -10.97% |
| 美股 / 梯度提升树 | 0.5131 | +12.79% | 0.373 | -5.41% |
| BTC / 比例基线 | 0.4905 | 0.00% | 0.000 | 0.00% |
| BTC / 逻辑回归 | 0.4736 | -48.88% | -0.658 | -54.64% |
| BTC / 梯度提升树 | 0.4924 | -72.83% | -1.236 | -79.03% |

比例基线每折预测一个训练集上涨频率，当前没有达到 0.55，因此始终持现金，收益为零。跨折基准概率会变化，所以合并 AUC 不一定恰好等于 0.5。

最重要的判断：

1. 美股树模型在 5 bps 下为正，但 10 bps 时变为 **-5.59%**。其 log-loss 0.6957 仍差于训练比例基线的 0.6923。20 天区块、500 次重采样的日均收益 95% 描述区间约为 **[-0.46, +1.67] bps**，包含零；这不是经过多重试验校正的显著性检验。
2. BTC 树模型即使零成本也为 **-32.51%**，不能把问题只归咎于手续费；当前特征/目标组合没有显示可部署的优势。
3. 不能把美股 v3 的 +12.79% 与旧六标的 v2 的 +1.15% 直接称作提升：资产组、时间窗口、做空规则、特征可用时间及训练方式都不同。
4. 所有数字都是按日线价格代理计算的理论研究结果，不是已成交 PnL。等权资金份额在缺失/FLAT 日期持现金，按日历日年化；没有完整模拟保证金、盘口容量或实时执行。

每组还提供同成本的“日内始终做多”基准，明确不是 buy-and-hold。报告同时保留所有候选及全部成本场景，不只展示最好的一行。

## 新增 section 各做什么

| 文件 | 用途 |
| --- | --- |
| `research/targets.py` | 按精确日期生成特征、标签与 UTC 时序；处理 BTC 双日滞后和美股交易日历 |
| `research/protocol.py` | 严格读取协议；冻结输入/源码/运行环境指纹，检测配置或数据变动 |
| `research/evaluation.py` | 时间可用性 purge、分组模型训练、long/flat 成本、基准、分标的归因和描述区间 |
| `research/cli.py` | 只读缓存的实验入口；新目录隔离写入；完成标记与结果完整性校验 |
| `configs/research_v3.toml` | 固定资产组、成本、模型、日期边界和验证设置 |
| `tests/test_research_*.py` | 40 项新增验证：时序、缺日、假日、成本、冻结、篡改、目录隔离、受保护文件不变 |

## 如何打开和复核

查看本次结果，不重新训练或修改数据：

```bash
.venv/bin/python main.py research show --run-dir artifacts/research-v3/20260907-timing-baseline
```

之后确实需要做一个新的预声明实验时，使用新的目录名：

```bash
.venv/bin/python main.py research run \
  --protocol configs/research_v3.toml \
  --run-dir artifacts/research-v3/new-experiment-id
```

该命令没有下载、broker 或自动部署路径；需要已有的 `data/yahoo/` 缓存。不要复用本次目录来覆盖结果。若要改规则，先保留旧协议、创建新协议与新实验，再明确它使用的是否仍是已经观察过的历史样本。

结果文件：`manifest.json` 是冻结证据，`predictions.csv` 是逐条预测，`report.json` 是完整评估，`completion.json` 是完整产物的哈希索引。当前 `show` 校验存储证据和结果哈希，不要求今天的数据/源码仍与旧实验完全相同。
