# Stage Completed: v3 Timing Targets and Frozen Experiment

Date: 2026-09-07. This stage performs offline research only, with no orders and no automatic selection or deployment of a winning model. Separate US-equity and BTC experiments were completed using the existing cache. SHA-256 hashes of the original v2 model, shadow database, report, and scheduled task were identical before and after the run; both order gates remained closed.

## What this stage resolves

Previously, “predict the next day” did not impose separate constraints on when market data become complete, when the model decides, or when labels become available for training. Each sample now explicitly records six UTC timing fields: feature date, feature availability, decision time, entry time, exit time, and label availability.

| Research group | Data used for target day D | Decision time | Price label |
| --- | --- | --- | --- |
| US equities/ETFs | Complete daily bars from exactly the preceding XNYS session | 00:30 UTC on D | Price proxy from the official open to the official close on D |
| BTC | Complete daily bars from D−2, deliberately adding a day of lag | 00:30 UTC on D−1 | Daily-price proxy from 00:00 on D to 00:00 on D+1 |

US equities use an exchange calendar for holidays, early closes, and daylight saving time. BTC no longer assumes that the preceding daily bar's closing data are known before that bar has finished. Rolling features require 21 complete, consecutive expected sessions. A sample is excluded when a required date is missing; an older day cannot be substituted automatically.

This is a **temporally feasible daily-bar research convention**, not a model with validated executable trades. Yahoo's adjusted OHLC data are still not historical point-in-time (PIT) raw quotes, and opening/closing prices are not guaranteed execution prices for this account. The 30 minute publication buffer is our assumption, not a vendor service guarantee. Entry methods still require validation against quotes, volume, order cutoffs, and latency.

## Freeze experiment rules before inspecting results

The rules are stored in `configs/research_v3.toml`:

- Research data end at 2026-09-03. The period beginning 2026-09-08 is reserved solely as a future research boundary; this run generated no v3 forward predictions and initiated no v3 trading.
- The SPY/JPM/XOM/WMT/JNJ equity group and the BTC group are trained and evaluated separately. They do not share a fitted model or combine returns into one number.
- Three predeclared baselines: training-set up frequency, logistic regression, and the current gradient-boosted tree. There is no hyperparameter search or retrospective threshold adjustment, only this single comparison.
- Fixed long/flat policy: assume a long position only when probability reaches 0.55; otherwise hold cash. There is no naked crypto shorting, stock borrowing, or options trading.
- Each group uses 6 expanding walk-forward folds, each with at most 252 group-specific dates, at least 1,260 training dates, and 5 purged dates.
- Additionally enforce `last training-label availability < first test-decision time`; equality is not allowed. This is more than offsetting feature-row numbers.
- Equity round-trip cost-stress scenarios are 0/5/10/20 bps, with 5 bps as the primary scenario. BTC scenarios are 0/10/25/50 bps, with 25 bps as primary. These are predefined engineering stress assumptions, not verified actual fee schedules.
- Regardless of scores, `research_only=true`, `executable_backtest=false`, and `promotion_disabled=true`. No deployable joblib is generated, and Paper admission is unchanged.

A manifest is written before execution, recording hashes of the protocol, all input data, source code, and dependency versions. Inputs are checked again after parsing and after computation. Results may be written only to a new `artifacts/research-v3/<run-name>/` directory. Existing directories, out-of-scope paths, and symlink traversal are rejected. `completion.json` is published only after every result has been saved successfully. Interrupted directories retain evidence and cannot appear completed.

Hashes provide verification, not digital signatures or archives of source code and raw data. Fully reproducing training years later would also require version control and read-only data snapshots. Earlier research has already inspected the historical data; freezing this run's rules cannot turn that history into a genuinely new holdout.

## Actual results: a larger model is not an automatic improvement

Run directory: `artifacts/research-v3/20260907-timing-baseline/`. The equity dataset has 32,930 rows and 7,560 out-of-sample rows; the BTC dataset has 4,348 rows and 1,512 out-of-sample rows. Across all three candidates, 27,216 out-of-time fold predictions were saved.

Different trading calendars produce different evaluation windows, so the groups' returns cannot be ranked directly: equities cover 2020-08-27 through 2026-09-03, while BTC covers 2022-07-15 through 2026-09-03.

| Group / model | AUC | Cumulative return after primary-scenario costs | Sharpe | Maximum drawdown |
| --- | ---: | ---: | ---: | ---: |
| Equities / frequency baseline | 0.5012 | 0.00% | 0.000 | 0.00% |
| Equities / logistic regression | 0.4984 | +3.66% | 0.164 | -10.97% |
| Equities / gradient-boosted tree | 0.5131 | +12.79% | 0.373 | -5.41% |
| BTC / frequency baseline | 0.4905 | 0.00% | 0.000 | 0.00% |
| BTC / logistic regression | 0.4736 | -48.88% | -0.658 | -54.64% |
| BTC / gradient-boosted tree | 0.4924 | -72.83% | -1.236 | -79.03% |

The frequency baseline predicts one training-set up frequency per fold. None currently reaches 0.55, so it always holds cash and earns zero return. Baseline probabilities change across folds, so pooled AUC need not equal exactly 0.5.

Key conclusions:

1. The equity tree model is positive at 5 bps but falls to **-5.59%** at 10 bps. Its log-loss of 0.6957 remains worse than the training-frequency baseline's 0.6923. With 20-day blocks and 500 resamples, the 95% descriptive interval for mean daily return is approximately **[-0.46, +1.67] bps**, which includes zero. This is not a multiple-testing-adjusted significance test.
2. The BTC tree model returns **-32.51%** even at zero cost, so fees alone cannot explain the result. The current feature/target combination has not demonstrated a deployable edge.
3. The equity v3 return of +12.79% cannot be called a direct improvement over the old six-symbol v2 return of +1.15%. Asset groups, time windows, shorting rules, feature availability, and training methods differ.
4. All figures are theoretical research results calculated from daily-price proxies, not executed PnL. Equal-weight capital sleeves remain in cash on missing/FLAT dates, with calendar-day annualization. Margin, displayed liquidity capacity, and real-time execution are not fully simulated.

Each group also includes an “always long intraday” benchmark at the same cost, explicitly distinct from buy-and-hold. Reports retain all candidates and cost scenarios, rather than displaying only the best row.

## Inspecting and verifying results

View this run without retraining or modifying data:

```bash
.venv/bin/python main.py research show --run-dir artifacts/research-v3/20260907-timing-baseline
```

When a genuinely new predeclared experiment is needed, use a new directory name:

```bash
.venv/bin/python main.py research run \
  --protocol configs/research_v3.toml \
  --run-dir artifacts/research-v3/new-experiment-id
```

This command has no download, broker, or automatic-deployment path and requires an existing `data/yahoo/` cache. Do not reuse this run's directory to overwrite results. To change the rules, first preserve the old protocol and create a new protocol and experiment, then explicitly state whether they still use previously inspected historical samples.

Result files: `manifest.json` contains the frozen evidence, `predictions.csv` contains individual predictions, `report.json` contains the complete evaluation, and `completion.json` is the artifact hash index. The current `show` command verifies stored evidence and result hashes; it does not require today's data or source code to remain identical to the old experiment.
